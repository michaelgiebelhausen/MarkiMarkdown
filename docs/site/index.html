What it is

The left side is the real Markdown, the code your note is made of. The right side is the same note, tidied up. Type on either side and the other keeps up, so you learn the code while you write. Nothing to memorise on day one.

Markdown in 60 seconds

# Headinga big heading (## and ### are smaller)
**bold**bold
*italic*italic
- itema bullet
1. itema numbered list
- [ ] taska checkbox
---a dividing line

Filing notes into your second brain

Down the left edge is the Funky Bunch: your AI agents on top, your folders underneath. Click whichever this note is relevant to and press File. Picking an agent picks the folders that agent reads. A copy goes into every folder you chose, the agents are written into the note itself, and each folder’s log.md records what arrived.
