# MarkiMarkdown 1.2.1

## The Funky Bunch grid, as pills

Skill folders now stand across the top as tall pills whose names read from the bottom up, and domain folders lie
down the side as wide pills. Each square is a rounded tile that shows how many notes sit there, or a blue dot
when both its skill and its domain are ticked. A ticked name turns blue. The emoji no longer sit beside the
names in the grid; you still see them in each member's settings and on the bunch chips.

## Downloads

The download button on the website now always fetches the newest installer, and its install guide links work
again.
